# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through
GitHub instead: go to the repository's **Security** tab and click **Report a
vulnerability**. Only ARMO maintainers can see the report.

Include what you found, how to reproduce it, and what an attacker could do with it. We
will acknowledge the report within three working days and keep you posted while we
work on a fix.

This covers the code in this repository and the server ARMO hosts at
`api.armosec.io/mcp` and `api.us.armosec.io/mcp`. Please test only against an ARMO
account you own, and don't access other customers' data.

## Supported versions

ARMO runs the latest release. Fixes go into `main` and ship from there; older releases
don't receive patches.
